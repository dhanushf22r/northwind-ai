# northwind-ai

An end-to-end applied AI project simulating a forward deployed engineering engagement at **Northwind Logistics**, a fictional mid-size freight company. Over 32 weeks it grows from synthetic support data into a production-grade assistant for support, operations and finance, alongside the consulting work a real engagement needs: discovery, specs, estimates, proposals and SOWs.

> Northwind, its people and all data in this repo are fictional. Every dataset is synthetic and generated by scripts in `data/` with a fixed seed.

## The client problem

Northwind runs 12 warehouses with 4,000 staff. It lost its largest customer after support took nine days to answer a question about a lost pallet. A previous chatbot project failed because it invented delivery dates.

The brief: show a measurable win in 30 days, a working system in six months, and a result leadership can defend in eight, at a cost the CFO will approve.

## Approach

- **Start narrow, measure everything.** Each build ships with an eval set, and changes are justified with numbers (accuracy, cost per answer, latency).
- **Grounded, not guessed.** Answers about policy or operations must cite source documents.
- **Production posture.** Tracing, guardrails, PII redaction, red-teaming and a runbook before anything faces users.
- **Each build reuses the last**, so the repo shows how a system evolves under changing requirements.

## Roadmap

| Build                       | What it demonstrates                                                  | Status         |
| --------------------------- | --------------------------------------------------------------------- | -------------- |
| Synthetic data generator    | Realistic support tickets with weighted urgency, categories and dates | 🟡 In progress |

| Support agent (deployed)    | Tool calling, memory, tracing, guardrails, containerised API          | ⚪ Planned     |

| Finance dispute agent       | MCP integrations, human approval, production deployment               | ⚪ Planned     |
| On-prem small model         | LoRA fine-tuning, local serving, cost vs hosted-model benchmark       | ⚪ Planned     |
| Integrated assistant        | Support, operations and finance in one system                         | ⚪ Planned     |

## Stack

Python · LangChain · LangGraph · Pydantic · FastAPI · Docker · Supabase (Postgres, pgvector) · LangSmith/Langfuse · RAGAS · MCP · AWS Bedrock · Ollama · Hugging Face

## Repo layout

```
northwind-ai/
  data/          # synthetic data generators (fixed seed)
  consulting/    # discovery notes, PRDs, estimates, proposals, SOWs
  evals/         # golden test sets and results (added with the first agent)
  <build>/       # one folder per build, each with its own README
```

Each build's README covers four things: the client problem, the decision made and why, the numbers, and what's next.

## Run it

```bash
git clone https://github.com/dhanushf22r/northwind-ai.git
cd northwind-ai
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python data/<generator>.py
```
